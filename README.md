### Sue Holder

I build agent harnesses: the guardrails, verification, supervision and context layers that decide whether an agent can be trusted to run when nobody is watching. Most of that work runs on my own systems. What is public sits here.

**[pix-harness](https://github.com/SPH73/pix-harness)** is the open part. It carries the identity guard today: a hashed denylist, four callers sharing the one list so they cannot drift, and a test that checks the guard itself rather than the code around it. A skill-trigger eval suite and a cost-and-usage account across the scheduled agents that run it are specified and dated in its README.

**[dev-tools](https://github.com/SPH73/dev-tools)** is a set of small, zero-dependency CLI tools for documentation and text pipelines.

**[absoluteSport-ssr-webapp](https://github.com/SPH73/absoluteSport-ssr-webapp)** is a Nuxt 4 application in production for a real client.

Python and TypeScript. Hosting on Vercel, Netlify, Supabase and cPanel.

Before software, I spent thirteen years founding and running Red Horse Mining Supplies, supplying patented rail-fastening products to blue-chip mining clients, after commercial and business-development roles across technical and industrial markets. The function throughout was the same: streamlining the processes and systems behind a business to improve its outcomes and its bottom line. I retrained in software in 2019 (Code Institute diploma) and have built and shipped for clients as a self-employed developer since 2021.

Based in West Sussex. [LinkedIn](https://linkedin.com/in/sueholder).
